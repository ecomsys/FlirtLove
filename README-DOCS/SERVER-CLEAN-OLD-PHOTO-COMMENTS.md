# КАК ЗАПУСТИТЬ ПРОЦЕСС АВТОМАТИЧЕСКОЙ ОЧИСТКИ СПАМА И ОТКЛООНЕННЫХ КОММЕНТАРИЕВ К ФОТО НА ПРОДЕ ?

Теперь всё централизовано в файле bootstrap/app.php через метод ->withSchedule().
```php
->withSchedule(function (Schedule $schedule) {
    // Очистка старых комментариев каждую ночь в 3:00
    $schedule->command('comments:clean --days=30')->dailyAt('03:00');
})
```

-- Когда сработает: Каждый день ровно в 03:00 ночи.
-- Что сделает: Запустит команду comments:clean с аргументом --days=30, которая удалит все rejected и spam комментарии старше 30 дней.
-- Архитектурно верно: Это современный подход Laravel 11/12, который избавляет от лишних файлов и держит всю конфигурацию приложения в одном месте.

## Как это работает под капотом:

В 03:00 системный Cron (на уровне ОС Linux) дергает команду php artisan schedule:run.
Laravel "просыпается", смотрит в bootstrap/app.php, видит твою настройку dailyAt('03:00') и понимает, что именно сейчас нужно её выполнить.
Он запускает твой класс CleanOldComments в app/Console/Commands/.

## ВАЖНО: Настройка Cron на боевом сервере

На локальной машине (особенно если у тебя Laravel Herd) планировщик может работать сам. Но когда ты выкатишь проект на VPS (Ubuntu/Debian), тебе обязательно нужно будет добавить одну единственную строку в crontab сервера.
Зайди на сервер по SSH и выполни:

```bash
crontab -e
```

И добавь в самый низ эту строку (заменив /path/to/your/project на реальный путь):

```bash
* * * * * cd /path/to/your/project && php artisan schedule:run >> /dev/null 2>&1
```

Эта строчка говорит системе: "Каждую минуту заходи в папку проекта и спрашивай у Laravel, нет ли у него задач на этот момент". А Laravel уже сам решит, запускать твою очистку или нет.

## Как протестировать прямо сейчас:

Чтобы не ждать 3 часа ночи, ты можешь запустить команду вручную и убедиться, что она работает:
```bash
php artisan comments:clean --days=30
```

или если не хочешь только 30 дневной давности, а хочешь вообще все (отколненные и спам) то передаешь 0 
```bash
php artisan comments:clean --days=0
```

(Для теста можешь временно поменять --days=30 на --days=0, чтобы удалить вообще всё, или создать фейковые старые записи в БД).
